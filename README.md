# 📊 Dashboard Comercial — Supermercado 2025

### Análisis de ventas, rentabilidad e inventario

## 📌 Sobre el proyecto

Este proyecto consiste en el desarrollo de un **dashboard comercial web interactivo**, orientado al análisis del desempeño de las ventas, la rentabilidad y la gestión del inventario de un supermercado durante el año 2025.

El objetivo es transformar datos comerciales en información visual y útil para analizar la facturación, comparar los puntos de venta, evaluar el rendimiento de las categorías de productos e identificar situaciones de stock crítico, facilitando la toma de decisiones basada en datos.

El análisis se realizó sobre una base de aproximadamente **64.960 registros de ventas** y un corte de inventario de 200 registros.

## 🎯 Objetivos del análisis

- Analizar la facturación total y el comportamiento mensual de las ventas.
- Evaluar la cantidad de operaciones y unidades vendidas.
- Comparar el desempeño comercial de los diferentes puntos de venta.
- Identificar las categorías de productos con mayor participación en las ventas.
- Analizar los costos y el margen bruto.
- Detectar productos con niveles de inventario inferiores al stock mínimo.
- Facilitar la exploración de los datos mediante filtros interactivos.

## ⚙️ Funcionalidades

- **Indicadores KPI:** facturación, operaciones, unidades vendidas y margen bruto.
- **Filtro por período:** selección de meses para analizar el comportamiento de las ventas.
- **Filtro por punto de venta:** selección múltiple para comparar diferentes sucursales.
- **Análisis de facturación:** comparación de ventas entre puntos de venta.
- **Análisis por categorías:** identificación de las categorías con mayor participación comercial.
- **Control de inventario:** detección de registros con stock inferior al mínimo establecido.
- **Gráfico Sunburst:** exploración jerárquica del stock crítico por punto de venta, categoría y producto.
- **Tabla de stock crítico:** identificación de productos que requieren reposición.
- **Conclusiones comerciales:** presentación de los principales hallazgos del análisis.
- **Exportación a PDF:** generación de informes para consulta y presentación.
- **Carga de Excel:** incorporación de los datos mediante un archivo externo.

## 📊 Principales indicadores y resultados

| Indicador | Resultado |
|---|---:|
| Facturación neta | $1.552.862.417,26 |
| Operaciones | 24.720 |
| Unidades vendidas | 274.615 |
| Registros de inventario | 200 |
| Registros con stock crítico | 17 |

### Principales hallazgos

- **MAY01** registró la mayor facturación, con $587.531.327,84, representando el 37,84 % del total.
- **PV02** presentó la menor facturación, con $230.564.845,91.
- **Frescos** fue la categoría con mayor participación en las ventas, con $359.147.709,35 (23,13 %).
- **PV03** presentó la mayor cantidad de unidades faltantes, con 50 unidades, distribuidas en 7 registros de inventario críticos.
- **Detergente 750 ml** requiere la reposición de 20 unidades para alcanzar su stock mínimo.

## 🧹 Preparación y procesamiento de datos

Durante la preparación de la información se realizaron tareas de revisión y organización de los datos:

- Normalización de categorías y campos descriptivos.
- Revisión de registros duplicados.
- Identificación y tratamiento de valores faltantes.
- Validación de fechas, importes y descuentos.
- Integración de información de ventas, productos e inventario.
- Organización de los datos para facilitar su análisis comercial.
